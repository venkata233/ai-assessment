## Expected failure modes
- **String-built SQL and N+1 queries**: check by: Use bound parameters; inspect query plans for the hot paths.
- **Naive URL validation (prefix checks, internal addresses)**: check by: Parse properly; reject unsafe schemes and internal targets; test adversarial inputs.
- **Stale cache entries, TTL longer than the data's validity**: check by: Define invalidation and expiry rules; test delete and expiry with a warm cache.
- **Work done inline on the request path; unbounded queues**: check by: Keep it off the hot path; bound and monitor the queue; test failure of the consumer.

## Review checklist
- Does every changed line have a reason I can state?
- Do tests fail when I break the code on purpose?
- Were error paths and concurrent use exercised?
- Were any versions, APIs, or facts taken from memory instead of checked?
- Is anything claimed that was not run?
